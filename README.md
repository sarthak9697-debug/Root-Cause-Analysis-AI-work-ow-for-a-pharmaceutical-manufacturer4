# Root-Cause-Analysis-AI-work-ow-for-a-pharmaceutical-manufacturer4
AI-powered Root Cause Analysis (RCA) application for pharmaceutical manufacturing that analyzes investigation documents, identifies potential causes, evidence gaps, 5 Whys, and CAPA actions. Built with React, Redux, FastAPI, LangGraph, Groq, and PostgreSQL, with human review and approval before finalizing RCA results.
